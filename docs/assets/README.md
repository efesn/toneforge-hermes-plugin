# Screenshot and demo assets

This directory is reserved for real captures of ToneForge running in Hermes and
AmpliTube. Nothing here is staged or mocked.

Planned files:

| File | Content |
|---|---|
| `hermes-create-preset.png` | Hermes chat showing a full `toneforge_create_preset` response |
| `hermes-adjust-preset.png` | Before/after change list from `toneforge_adjust_preset` |
| `amplitube-midi-learn.png` | AmpliTube 5 MIDI Learn dialog with a CC assigned |
| `demo.mp4` | 90-second walkthrough from prompt to moving knob |

Capture instructions, narration and shot list: [`../DEMO_SCRIPT.md`](../DEMO_SCRIPT.md).

Guidelines:

- Capture the real UI state; do not edit values into a screenshot.
- Do not include personal paths, email addresses, tokens, or unrelated windows.
- Crop to the relevant window; keep text legible at 1x.
